动画《我的青春恋爱物语果然有问题》人气女主的桌宠
Yukino Pet 独立桌宠
====================

双击 YukinoPet.exe 即可运行，不需要启动 ChatGPT 或 Codex。

操作：
- 按住左键拖动：移动桌宠，同时播放左右跑步动画。
- 单击：克制地打招呼。
- 鼠标悬停：不会再自动跳跃。
- 右键：动作、暂停、缩放、置顶、隐藏和退出。
- 隐藏后可在系统托盘双击雪乃图标重新显示。

设置保存在：%LOCALAPPDATA%\YukinoPet\settings.ini
删除该目录即可重置位置和大小。

这是 Windows 便携版；不连接 ChatGPT，因此不会自动显示聊天任务状态。

程序由本机直接编译，没有商业代码签名证书。若 Windows SmartScreen 显示“未知发布者”，可在确认压缩包来源无误后选择“更多信息 → 仍要运行”。
